# KC Ken Pierson — Personal Portfolio Website

Welcome to the personal portfolio website of **KC Ken Pierson**, Founder of **Thought-Life Connection**, Recovery Educator, and Speaker based in Santa Clarita, California.

## About This Project
This is a modern, responsive single-page portfolio website built to showcase:
- **Core Programs:** Thought-Life Connection, 1-Year Home-Study Recovery Course, and Seminars/Workshops.
- **Experience:** Over two decades of leadership and counseling psychology in addiction recovery and cognitive transformation.
- **Philosophy:** Practical integration of 12-Step insights, cognitive awareness, and compassionate guidance.
- **Direct Contact:** Access to website, email, phone, and professional profiles.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## Getting Started
To run this project locally:

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
